# Historia de Usuario: C-01 - Autenticación

**Como** comprador, **quiero** iniciar sesión con email y contraseña, **para** acceder a mi cuenta de comprador.

---

## Criterios de Aceptación

**AC-001 – Validar funcionalidad principal**
Dado que soy comprador, cuando intento acceder o ejecutar la acción de iniciar sesión con email y contraseña, entonces:
* El login funciona en <2s; máximo 3 intentos fallidos antes de bloqueo temporal

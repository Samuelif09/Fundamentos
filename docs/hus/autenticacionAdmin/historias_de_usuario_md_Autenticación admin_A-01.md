# Historia de Usuario: A-01 - Autenticación admin

**Como** admin, **quiero** iniciar sesión con credenciales seguras, **para** acceder al panel de administración.

---

## Criterios de Aceptación

**AC-001 – Validar funcionalidad principal**
Dado que soy admin, cuando intento acceder o ejecutar la acción de iniciar sesión con credenciales seguras, entonces:
* Login exclusivo admin con 2FA obligatorio; sesión expira en 4h de inactividad

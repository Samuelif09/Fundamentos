# Historia de Usuario: S-02 - Publicar libro

**Como** vendedor, **quiero** publicar un libro con título, descripción y precio, **para** que compradores lo encuentren.

---

## Criterios de Aceptación

**AC-001 – Validar funcionalidad principal**
Dado que soy vendedor, cuando intento acceder o ejecutar la acción de publicar un libro con título, descripción y precio, entonces:
* El libro aparece en el catálogo dentro de 24h tras ser aprobado por el admin
